# 政治一页纸 · 真一页 · v1.2.11

同一批考点做了个更窄的版本：不要卡片，不分页，从马原一路铺到最后一节，一页读完。

在线打开：https://kkdlm.github.io/politics-true-one-page/

## 用法

- 顶上两个按钮在「通读」和「挖空」之间换。挖空是把考点词盖成灰块，点一下露出来，切走再回来又盖上；右下角可以全部揭示或重新遮住。
- 搜索、板块筛选、打勾、收藏都在。手机上随手翻一遍挺快，平板也能开。
- 移动端适配：禁双指/双击缩放、无橡皮筋回弹、右侧无滚动指示条（含设置面板内部滚动区）、下滑超 420px 浮出回到顶部。
- 启动屏：不显示提示，正常停 3 秒自动淡出；点一下立即进入且不误触底层界面。

内容同样来自《2027 这就是一页纸·知识点手册》，自己复习用，不传播。
