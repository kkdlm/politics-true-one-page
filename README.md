# 政治一页纸 · 真一页

2027 考研政治知识点背诵程序 —— **100 个考点全文铺在一页上连续通读**，同一页切换「通读 / 挖空」两种状态。

## 打开方式

- GitHub Pages（推荐，可加到主屏）：https://kkdlm.github.io/politics-true-one-page/
- 备用直链：https://aka.doubaocdn.com/s/C1Cxo0NRov

## 我的密钥（免注册存档）

顶部齿轮 / 右上 ⚙ → 「**我的密钥**」：

1. 输入自定义密钥（至少 4 位），点**保存密钥**；
2. 点**生成同步码**，得到一段 `YZ1.` 开头的密文（约 200 字符，一条微信就能发）；
3. 换设备打开同一程序 → 输入**同一把密钥** → 点**粘贴恢复** → 粘上那段码，掌握、收藏、复习排期就全回来。

- 不注册账号、不上传任何第三方服务器，密钥只存在本机；
- 同步码用 AES-GCM(256) + PBKDF2（12000 轮、固定盐）加密，密钥不对则解密失败；
- 恢复会覆盖本机当前掌握 / 收藏 / 排期（会二次确认）。

## 功能

- **通读**：9 章节 + 100 条连续文档流，无卡片折叠，从马原一路读到「其他」。
- **挖空**：逐词遮盖 1,930 个考点词，灰块保留原词宽度；点词揭示，切走再切回自动复遮；右下角「全部揭示 / 重新遮住」。
- **搜索 / 筛选**：标题正文全匹配；全部 / 待复习 / ★收藏 / 未掌握 + 9 板块。
- **标记**：`○→✓` 已掌握（自动排 4 天后复习）、`☆→★` 收藏；顶部环形进度。
- **设置**：浅色 / 夜间、三档字号、我的密钥、导出 / 导入、清空记录。
- **离线**：单文件自包含，零外部请求。
